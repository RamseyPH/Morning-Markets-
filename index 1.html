Important: London-listed GBX ETFs are closed between 16:30 and 07:00, so their own prices cannot measure an overnight move. The percentage column therefore uses the live underlying benchmark from Twelve Data; the GBX ticker is a single reference link only. Calculation: latest benchmark level ÷ nearest available 15-minute level at or before 16:30 London on the previous UK trading day − 1. If the API does not provide both observations, the row is marked unavailable. Manual refresh only; eight markets use eight API requests.
